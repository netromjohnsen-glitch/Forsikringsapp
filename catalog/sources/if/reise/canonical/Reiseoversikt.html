Trygghet på alle reiser

Vi har lang erfaring med å hjelpe deg på reise, både på små og store eventyr. Med If ved din side får du rask hjelp når du trenger det, uansett hvor i verden du er.

Velg forsikring

  • Helårs reiseforsikring
  • Enkeltreiseforsikring
  • Student i utlandet
  • Ung start
  • Reiseforsikring via jobb
  • Ekspedisjon
  • Søk / redning Svalbard
  • Melde skade Vi er her for å hjelpe deg ved sykdom og skade på reise, uansett hvor du er i verden.
  • Hjelp på reisen Vi er aldri langt unna, og kan hjelpe deg der du er. Les mer om If reisehjelp.

If reise-appen

Med If reise-appen kan du raskt melde skade, få medisinsk hjelp på reisen, hente frem reiseforsikringsbeviset ditt og mye annet. Last ned den i dag, så har du hjelpen lett tilgjengelig om noe skulle skje på reisefot.

Last ned appen!

SmartDelay+

Hvis flyet ditt blir forsinket, får du med Super reiseforsikring tilgang til flyplasslounge eller utbetaling med tjenesten SmartDelay+. Husk å registrere flyreisene minst 24 timer før avreise.

Les om tjenesten!
