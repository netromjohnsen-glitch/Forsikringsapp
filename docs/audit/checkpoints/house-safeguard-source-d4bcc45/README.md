av inneholdende commit på remote main. Bare hus.sikkerhet.egenandelsfritak er rettet
fra Standard-side 18 til 17; Pluss arver samme Standard-rad og kildeeier.

beholdes. Se receipt-house-safeguard-source.json, validation-summary.json og checkpoint.json.
