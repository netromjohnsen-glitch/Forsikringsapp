55 – ROOT CAUSE MUST NOT BE ASSUMED
==================================================

A missing visible comparison fact can originate from several layers:

SOURCE
→ source package incomplete

EXTRACTION / SOURCE PARSING
→ source contains fact but audit/parser misses it

CATALOG
→ source fact never entered

CANONICAL MODEL
→ no suitable semantic representation exists

INHERITANCE
→ fact exists but is not inherited to correct product

ADD-ON
→ fact belongs to optional component but is attached incorrectly

APPLICABILITY
→ fact is valid only for specific product/type/version

PRESENTATION
→ catalog contains fact but UI does not expose it.

Trace enough evidence to distinguish these.
