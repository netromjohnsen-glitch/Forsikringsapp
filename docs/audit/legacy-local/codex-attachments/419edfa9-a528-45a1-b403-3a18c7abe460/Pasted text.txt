==================================================

A good triage does NOT maximize the number of remediation batches.

independently testable,
low-blast-radius remediation batches

==================================================

A remediation batch is coherent when its findings share:

the same semantic mechanism

==================================================

Split a proposed batch when:

- different canonical semantics are involved
- different source certainty applies
- different agreement scopes apply
- one subset requires architecture work
- one subset requires source research
- regression blast radius differs materially
- fixes would touch unrelated implementation layers.

==================================================

Merge batches only when:

- same root mechanism is proven
- same implementation layer applies
- source evidence is independently settled
- regression plan can safely cover combined scope.
